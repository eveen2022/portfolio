CSS Grid solved layout problems that used to require hacky float or flexbox workarounds.

## The Basics

A grid container needs just two properties to get started:

- `display: grid`
- `grid-template-columns`

From there you can place items precisely using line numbers or named areas.

## Why I Reach For It

Flexbox is one-dimensional. Grid is two-dimensional. When I need to control both rows and columns at once — like a dashboard layout — grid wins every time.
